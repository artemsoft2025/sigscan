## Что это

`sigscan` — утилита для снятия сигнатур с PE-файлов (EXE/DLL/SYS/OCX/CPL/SCR)
и сканирования файлов и папок по базе сигнатур.

Типичные сценарии:

- снять сигнатуру с подозрительного файла и сохранить её в базу;
- просканировать диск или папку на совпадения с известными образцами;
- разово проверить файл по конкретной сигнатуре без базы.

**Это не антивирус.** Утилита не выносит вердиктов «вирус / не вирус».
Она показывает факты: «этот файл совпал с записью X на 3/3 сигнатур».
Решение — за пользователем.

---

## Особенности

Автоматически снимает сигнатуы с программного файла. 

## Как это работает

#### Снятие сигнатур

1. Берётся PE-файл.
2. Находится секция `.text` (машинный код).
3. Скользящим окном 64 байта ищутся фрагменты с высокой энтропией
   (4.5–7.0). Скоринг: `-abs(энтропия - 6.0) + уникальные_байты × 0.02`.
4. Отбираются 3 сигнатуры с расстоянием ≥1024 байт друг от друга.
5. Сигнатуры сохраняются в базу (или показываются на экран).

#### Зачем именно так

Обычный хеш (SHA-256) ловит только **точную копию**. Один изменённый
байт — и хеш другой. Сигнатуры из `.text` устойчивы к мелким
модификациям: пересборке, патчу, обновлению версии.

- **`.text`** — код, а не данные. Сигнатуры из кода стабильнее.
- **64 байта** — баланс между уникальностью и устойчивостью к патчам.
- **Высокая энтропия** — плотный код, а не однородные данные.
- **3 сигнатуры** — если одна задета патчем, две другие выживут.

#### Поиск

По **всему файлу**, а не только по `.text`. Точное побайтовое совпадение.
Никаких wildcards, никаких regex.

64 байта — слишком длинная последовательность для случайного
совпадения. Модифицированный файл может иметь сигнатуру вне `.text`.

## Вердикты

| Вердикт        | Что значит                                          |
| -------------- | --------------------------------------------------- |
| `COPY`         | SHA-256 совпал — это тот же файл (или точная копия) |
| `EXACT_MATCH`  | Все сигнатуры записи найдены (например, 3/3)        |
| `STRONG_MATCH` | ≥ `hits_required` сигнатур (по умолчанию 2/3)       |
| `WEAK_MATCH`   | ≥1, но меньше `hits_required` — FP или модификация  |
| `CLEAN`        | Ни одна сигнатура не найдена                        |

`COPY` сильнее `EXACT_MATCH`: если sha256 совпал, это буквально тот же
файл, независимо от сигнатур.

## Быстрый старт

1. Скопируйте `sigscan.exe` в удобную папку:
   C:\Tools\sigscan\

2. Рядом создайте папку `signatures\`:
   `C:\Tools\sigscan\signatures`\

База создастся автоматически при первом добавлении записи.

3. Снять 3 сигнатуры с файла и сохранить в базу:

```
sigscan.exe gen C:\suspicious.exe --save Bad.Example
```

Посмотреть, что в базе:

```
sigscan.exe db list
```

Просканировать папку:

`sigscan.exe scan C:\Users\user\Downloads --progress`

Проверить один файл:

`sigscan.exe scan C:\suspicious.exe`

Разово проверить по одной сигнатуре (без базы):

`sigscan.exe scan C:\ --sig "0F 47 F8 48 8B CD ..."`

## Команды

`gen <file>`

Снять сигнатуры с PE-файла и вывести на экран. Опционально — сохранить в базу.

```
--count N          сколько сигнатур снять (по умолчанию 3)
--min-gap N        мин. расстояние между сигнатурами (1024)
--compact          выводить без пробелов: 0F47F8...
--both             выводить оба формата
--save NAME        сохранить в базу под указанным именем
--db DIR           папка базы (по умолчанию signatures)
--force            перезаписать запись с тем же именем
```

`scan <path>`

Просканировать файл или папку по базе.

```
--db DIR           папка базы; можно несколько раз или через запятую
--sig HEX          сканировать по одной сигнатуре, без базы
--min-hits N       показывать записи с hits >= N (по умолчанию 1)
--min-size SIZE    пропускать файлы меньше SIZE (1K, 100M)
--max-size SIZE    пропускать файлы больше SIZE (100M, 2G)
--ext .exe,.dll    только указанные расширения
--programs         только .exe .scr .cpl
--all              все файлы, без фильтра
--skip DIRS        пропустить папки (через запятую)
--limit N          остановиться после N файлов
--progress         печатать счётчик
--quiet            не печатать offsets
--log FILE         лог в файл
--ext, --programs, --all — взаимоисключающие.
```

`db add <file> --name NAME
`
Снять сигнатуры и добавить запись в базу одной командой.

```
--name NAME        имя записи (обязательно)
--count N          сколько сигнатур снять (3)
--min-gap N        мин. расстояние (1024)
--db DIR           папка базы
--force            перезаписать
--compact          выводить без пробелов
```

`db list`

Показать все записи в базе. Поддерживает несколько `--db`.

`db remove <name>`

Удалить запись по имени.

## Формат сигнатур

Сигнатура — 64 байта в hex. Принимается и выводится в двух форматах:

```
с пробелами:  0F 47 F8 48 8B CD 48 8B D7 ...
без пробелов: 0F47F8488BCD488BD7...
```

На экран по умолчанию выводятся с пробелами (для глаз), в базе хранятся
без пробелов (компактно).

При вводе через `--sig` принимаются оба формата и любой регистр:

```
0F 47 F8 ...
0f47f8...
0F<TAB>47<NL>F8...
```

Не поддерживаются:

- многоточие ... — это обрезка из примеров, а не часть сигнатуры;

- `wildcards ??` — не реализованы.

## База сигнатур

База — папка (по умолчанию `signatures/`) с файлом `index.json`:

```
signatures/
└── index.json
```

Запись содержит:

```
Поле    Что это
id    12 hex-символов, стабильный идентификатор
name    имя записи
sha256    SHA-256 исходного файла
size    размер исходного файла
created    дата создания (UTC, ISO 8601)
signatures    список hex-сигнатур
hits_required    порог для STRONG_MATCH
```



Запись атомарна: сначала пишется временный файл, потом os.replace.


Прерывание процесса не портит базу.



Несколько баз можно использовать одновременно:

```

sigscan.exe scan C:\ --db signatures --db downloaded
sigscan.exe scan C:\ --db "signatures,downloaded"
```


Записи из всех баз объединяются.

## Пропуск папок

По умолчанию сканер не пропускает ничего. Если указан`C:\` — сканируется всё, включая `Temp, WinSxS, $Recycle.Bin, AppData`.

Это осознанное решение: зловред может спрятаться в любой папке.

### Ускорение — через `--skip`:


`sigscan.exe scan C:\ --skip "winsxs,installer,driverstore"`


Имена папок регистронезависимые, через запятую. Пропускается папка
с таким именем на любом уровне вложенности.



Рекомендация: пропускайте WinSxS. Это папка с копиями системных файлов Windows. Сканировать её бессмысленно: файлы дублируют System32, а если вирус заменил файл в System32, копия в WinSxS останется чистой. Пропуск ускоряет сканирование в разы.

## Логи

`--log FILE` пишет лог в файл дополнительно к обычному выводу.

```

2026-09-26 10:49:22 scan start: C:\Windows\System32
2026-09-26 10:49:22 db: signatures (2 entries)
2026-09-26 10:49:27 hit: C:\Windows\System32\notepad.exe [COPY] Test.Notepad 3/3
2026-09-26 10:50:11 scan done: found=1
```


Лог не ротируется. Если сканируете часто, следите за размером.



## Что sigscan не делает

- Не работает с текстовыми скриптами (.bat, .ps1, .vbs, .js, .hta). Для них — утилита **strscan**.

- Не выносит вердиктов «вирус / не вирус». Только показывает факты.

- Не поддерживает wildcards в сигнатурах.

- Не поддерживает регулярные выражения.

- Не распаковывает архивы.

- Не анализирует .lnk (ярлыки).



## Ограничения

Нет `gen --batch`. Снятие сигнатур с папки — вручную по одному файлу. В справке есть пример bat-скрипта для автоматизации
