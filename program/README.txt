--------------------------------------------------------------------------------
 ЧТО ЭТО
--------------------------------------------------------------------------------

sigscan — утилита для снятия сигнатур с PE-файлов (EXE/DLL/SYS/OCX/CPL/SCR)
и сканирования файлов и папок по базе сигнатур.

Типичные сценарии:
  - снять сигнатуру с подозрительного файла и сохранить её в базу;
  - просканировать диск/папку на совпадения с известными образцами;
  - разово проверить файл по конкретной сигнатуре без базы.

Сигнатуры снимаются стратегией: окна по 64 байта внутри секции .text
с высокой энтропией (4.5–7.0). Это единственная стратегия, которая
эмпирически дала 0 ложных срабатываний на ~56 000 системных файлах
Windows (System32, Program Files, SysWOW64).

Это НЕ антивирус. Утилита не выносит вердиктов «вирус / не вирус».
Она показывает ФАКТЫ: «этот файл совпал с записью X на 3/3 сигнатур».
Решение — за пользователем.

--------------------------------------------------------------------------------
 УСТАНОВКА
--------------------------------------------------------------------------------

1. Скопируйте sigscan.exe в удобную папку, например:

     C:\Tools\sigscan\

2. Рядом с sigscan.exe создайте папку signatures\:

     C:\Tools\sigscan\signatures\

3. База создастся автоматически при первом добавлении записи.

Внешних зависимостей нет. Всё внутри EXE.

--------------------------------------------------------------------------------
 БЫСТРЫЙ СТАРТ
--------------------------------------------------------------------------------

1. Первый запуск — посмотреть справку:

     sigscan.exe --help

2. Снять 3 сигнатуры с файла и посмотреть их:

     sigscan.exe gen C:\path\to\target.exe --both

3. Снять сигнатуры и сразу сохранить в базу:

     sigscan.exe gen C:\path\to\target.exe --save MyMalware.A

4. Посмотреть, что лежит в базе:

     sigscan.exe db list

5. Просканировать папку:

     sigscan.exe scan C:\Windows\System32 --progress

6. Просканировать по одной сигнатуре, без базы:

     sigscan.exe scan C:\path --sig "0F 47 F8 48 8B CD ..."

7. Удалить запись из базы:

     sigscan.exe db remove MyMalware.A

--------------------------------------------------------------------------------
 КОМАНДЫ
--------------------------------------------------------------------------------

sigscan.exe gen <file>
    Снять сигнатуры с PE-файла и вывести их на экран.
    Опционально сохранить в базу.

    --count N          сколько сигнатур снять (по умолчанию 3)
    --min-gap N        мин. расстояние между сигнатурами в файле
                       (по умолчанию 1024 байта)
    --compact          выводить без пробелов:  0F47F8...
    --both             выводить оба формата (с пробелами и без)
    --save NAME        сохранить в базу под указанным именем
    --db DIR           папка базы (по умолчанию signatures)
    --force            перезаписать запись с тем же именем

sigscan.exe scan <path>
    Просканировать файл или папку по базе (или по одной сигнатуре).

    --db DIR           папка базы; можно указать несколько раз или
                       через запятую: --db a --db b  или  --db "a,b"
                       (по умолчанию signatures)
    --sig HEX          сканировать по одной сигнатуре, без базы
    --min-hits N       показывать записи с hits >= N (по умолчанию 1)
    --min-size SIZE    пропускать файлы меньше SIZE (примеры: 1K, 100M)
    --max-size SIZE    пропускать файлы больше SIZE (примеры: 100M, 2G)
    --ext .exe,.dll    сканировать только указанные расширения
    --programs         сканировать только .exe .scr .cpl
    --all              сканировать все файлы, без фильтра по расширению
    --skip DIRS        пропустить папки с указанными именами
                       (через запятую); по умолчанию ничего не пропускается
    --limit N          остановиться после N файлов
    --progress         печатать счётчик просканированных файлов
    --quiet            не печатать offsets совпадений
    --log FILE         писать лог в файл (дополнительно к stderr)

    --ext, --programs, --all — взаимоисключающие.

sigscan.exe db add <file> --name NAME
    Снять сигнатуры и добавить запись в базу одной командой.

    --name NAME        имя записи (обязательно)
    --count N          сколько сигнатур снять (по умолчанию 3)
    --min-gap N        мин. расстояние между сигнатурами
    --db DIR           папка базы
    --force            перезаписать запись с тем же именем
    --compact          выводить сигнатуры без пробелов

sigscan.exe db list
    Показать все записи в базе (или в нескольких базах).

    --db DIR           папка базы; можно несколько раз или через запятую

sigscan.exe db remove <name>
    Удалить запись по имени.

    --db DIR           папка базы
	
Пояснение:
gen <file> --save NAME и db add <file> --name NAME делают одно и то же (снимают 
сигнатуры и сохраняют в базу), разница только в выводе: gen --save показывает 
метаданные файла, db add — метаданные записи.

--------------------------------------------------------------------------------
 ФОРМАТ СИГНАТУР
--------------------------------------------------------------------------------

Сигнатура — это 64 байта в hex. Принимается и выводится в двух форматах:

  с пробелами:  0F 47 F8 48 8B CD 48 8B D7 ...
  без пробелов: 0F47F8488BCD488BD7...

Оба формата эквивалентны. На экран по умолчанию выводятся с пробелами
(удобнее для глаз), в базе хранятся без пробелов (компактнее).

При вводе через --sig принимаются оба формата и любой регистр:
  0F 47 F8 ...
  0f47f8...
  0F<TAB>47<NL>F8...

Не поддерживаются:
  - многоточие ...  (это обрезка из примеров, а не часть сигнатуры);
  - wildcards ??    (не реализованы в текущей версии).

--------------------------------------------------------------------------------
 ВЕРДИКТЫ ПРИ СКАНИРОВАНИИ
--------------------------------------------------------------------------------

COPY          SHA-256 просканированного файла совпадает с сохранённым
              в записи. Это тот же самый файл (или его точная копия).
              Самый сильный вердикт.

EXACT_MATCH   Найдены все сигнатуры записи (например, 3/3).

STRONG_MATCH  Найдено не меньше hits_required сигнатур (по умолчанию
              hits_required = ceil(2/3 от общего числа)). Для 3 сигнатур
              это 2/3.

WEAK_MATCH    Найдена хотя бы одна сигнатура, но меньше hits_required.
              Возможен ложный или модифицированный образец.

CLEAN         Ни одна сигнатура не найдена.

--------------------------------------------------------------------------------
 БАЗА СИГНАТУР
--------------------------------------------------------------------------------

База — это папка (по умолчанию signatures/) с файлом index.json:

  signatures/
  └── index.json

Запись в index.json содержит:

  id            12 hex-символов, стабильный идентификатор
  name          имя записи (то, что указал пользователь)
  sha256        SHA-256 исходного файла
  size          размер исходного файла в байтах
  created       дата создания записи (UTC, ISO 8601)
  signatures    список hex-сигнатур без пробелов
  hits_required сколько сигнатур нужно найти для STRONG_MATCH

Запись в базу всегда атомарна: сначала пишется временный файл,
потом os.replace. Прерывание процесса не портит базу.

Несколько баз можно использовать одновременно:

  sigscan.exe scan C:\ --db signatures --db downloaded

или:

  sigscan.exe scan C:\ --db "signatures,downloaded"

Записи из всех баз объединяются, дубликаты по имени не схлопываются —
пользователь увидит все совпадения.

--------------------------------------------------------------------------------
 ПУТИ ПО УМОЛЧАНИЮ
--------------------------------------------------------------------------------

База сигнатур:  .\signatures\         (относительно текущей директории)
Лог (--log):    не пишется, если не указан

Если запускаете из другой директории — указывайте --db явно, либо
перейдите в директорию с базой. Рекомендуется класть базу рядом
с sigscan.exe и запускать из этой папки.

--------------------------------------------------------------------------------
 ПРОПУСК ПАПОК
--------------------------------------------------------------------------------

По умолчанию сканер НЕ пропускает ничего. Если указан диск C:\ —
сканируется всё, включая Temp, WinSxS, $Recycle.Bin, AppData.

Это осознанное решение: зловред может спрятаться в любой папке,
и сканер должен его найти.

Если нужно ускорить сканирование большого диска, можно явно указать,
какие папки пропустить:

  sigscan.exe scan C:\ --skip "winsxs,installer,driverstore"

Имена папок — регистронезависимые, через запятую. Пропускается
папка с таким именем на любом уровне вложенности. Для имён
с пробелами используйте кавычки: --skip "my folder,tmp".

Типичный быстрый скан:

  sigscan.exe scan C:\ --skip "winsxs,installer,driverstore,assembly,$recycle.bin,system volume information,temp,tmp,cache"

РЕКОМЕНДАЦИЯ: пропускайте WinSxS. Это папка с копиями системных
файлов Windows. Сканировать её бессмысленно: файлы там дублируют
System32, а если вирус заменил файл в System32, копия в WinSxS
останется чистой. Это ускорит сканирование в разы.

--------------------------------------------------------------------------------
 ЛОГИ
--------------------------------------------------------------------------------

Флаг --log FILE пишет лог в файл дополнительно к обычному выводу.
Формат: текстовый, с timestamp в начале строки.

Пример:

  2026-09-26 10:49:22 scan start: C:\Windows\System32
  2026-09-26 10:49:22 db: signatures (2 entries)
  2026-09-26 10:49:27 hit: C:\Windows\System32\notepad.exe [COPY] Test.Notepad 3/3
  2026-09-26 10:50:11 scan done: found=1

Внимание: лог НЕ ротируется. Если сканируете часто, следите за
размером или периодически удаляйте старый.

--------------------------------------------------------------------------------
 ЧТО НЕ ДЕЛАЕТ SIGSCAN
--------------------------------------------------------------------------------

- Не работает с текстовыми скриптами (.bat/.ps1/.vbs/.js/.hta).
  Для них — strscan (отдельная утилита).
- Не выносит вердиктов «вирус / не вирус». Только показывает факты.
- Не поддерживает wildcards в сигнатурах. Только точное совпадение.
- Не поддерживает регулярные выражения.
- Не распаковывает архивы.
- Не анализирует .lnk (ярлыки).

--------------------------------------------------------------------------------
 ОГРАНИЧЕНИЯ ТЕКУЩЕЙ ВЕРСИИ
--------------------------------------------------------------------------------

- Одна стратегия снятия сигнатур: A (высокоэнтропийные окна в .text).
  Стратегия D (.rsrc, семейные сигнатуры) запланирована, но не реализована.
  Стратегии B, C, E, F, G эмпирически провалились, не используются.

- Нет пакетного режима gen --batch. Снятие сигнатур с папки — вручную
  по одному файлу. Ниже есть пример bat-скрипта для этой задачи.

- Нет db export / import. Перенос базы — вручную копированием папки.

- Нет wildcards в сигнатурах. Только точное побайтовое совпадение.

--------------------------------------------------------------------------------
 СВЯЗАННЫЕ ПРОЕКТЫ
--------------------------------------------------------------------------------

strscan — отдельная утилита для сканирования текстовых скриптов
(.bat, .cmd, .ps1, .vbs, .js, .hta) по списку подозрительных строк.

Не путать: sigscan — про PE-файлы и байтовые сигнатуры,
strscan — про скрипты и строки. Проекты независимы.


--------------------------------------------------------------------------------
db-add-folder.bat — добавляет все PE-файлы из папки в базу
--------------------------------------------------------------------------------
@echo off
setlocal

REM sigscan — add all PE files from a folder to the database.
REM Does NOT scan subfolders — only the specified folder.
REM Entry name = filename with extension (malware.exe -> malware.exe).

set DIR=%~1
if "%DIR%"=="" (
    echo Usage: %~nx0 ^<folder^>
    echo Example: %~nx0 C:\vir
    exit /b 1
)

if not exist "%DIR%" (
    echo ERROR: not found: %DIR%
    exit /b 1
)

echo Folder: %DIR%
echo.

set ADDED=0
set SKIPPED=0

for %%F in ("%DIR%\*.exe" "%DIR%\*.dll" "%DIR%\*.sys" "%DIR%\*.ocx" "%DIR%\*.cpl" "%DIR%\*.scr") do (
    if exist "%%F" (
        sigscan.exe db add "%%F" --name "%%~nxF" --compact >nul 2>&1
        if errorlevel 1 (
            echo   skip: %%~nxF
            set /a SKIPPED+=1
        ) else (
            echo   added: %%~nxF
            set /a ADDED+=1
        )
    )
)

echo.
echo Done. Added: %ADDED%  Skipped: %SKIPPED%
endlocal

Что делает

Принимает папку как аргумент.
Обходит только эту папку, без подпапок.
Для каждого PE-файла — sigscan.exe db add <file> --name <filename>.
Имя записи = имя файла с расширением (malware.exe → malware.exe). Так два файла с одинаковым именем, 
но разными расширениями не конфликтуют.
Если файл не PE или уже в базе — пропускает.
Печатает счётчики.
